# Планы и идеи

## Сделано (0.1 → 0.11.3)

Захват области и выделенного текста, OCR (текст / таблица / формула), перевод EN/RU/UK/ZH, грамматика, свои действия, словарь терминов, повтор последней области и перевод поверх оригинала, пиньинь и озвучка, QR, менеджер моделей с подбором по видеопамяти и автоустановкой llama.cpp, автообновление, автозапуск, тёмная тема, голосовой ввод (перевод и диктовка в программу), перевод файлов (txt/srt/docx/pptx/pdf/картинки), docx/pptx с сохранением оформления, история на диске с поиском, Keep window open, Open last window.

## Не проверено вживую (просить скриншоты при случае)

- Open last window (0.11.3), перевод .docx/.pptx на реальных документах владельца, выбор микрофона, «Send to» в Проводнике, перетаскивание файлов в окно.

## Предложено владельцу, не выбрано

- Горячая клавиша для «Open last window» (например Ctrl+Shift+Win+L).
- Субтитры .srt/.vtt: перевод только текста реплик, номера и тайминги гарантированно не трогаются.
- Пакетный перевод папки с файлами.
- Режим «переводчик буфера»: закреплённое окно переводит всё, что копируется (Ctrl+C).

## Другие идеи

- Глобальная клавиша «перевести и заменить» для документов Word прямо в открытом файле.
- Сохранение «последнего окна» между перезапусками.
- Своя голосовая модель для 26B/31B (отдельный маленький Gemma E2B только для речи).
- Проверка грамматики длинных текстов по частям (сейчас до 8000 символов).

# n17 YuHelper

[English](README.md) · **Українська**

Програма для Windows у треї, схожа на ShareX: натисніть гарячу клавішу, виділіть область екрана, візьміть виділений текст або просто скажіть уголос — і програма **розпізнає, перекладе чи перевірить** текст за допомогою ШІ-моделей, що працюють **на вашому комп'ютері** (llama.cpp). Нічого не надсилається в інтернет.

- **Розпізнавання тексту (OCR)** будь-якої області екрана: текст, таблиці (вставка в Excel / Word), формули (LaTeX), QR-коди
- **Переклад** між англійською, українською, російською, китайською та багатьма іншими мовами, зі словником власних термінів
- **Перевірка граматики та правопису** з підсвіткою виправлень; одна клавіша — і виправлений текст замінює оригінал
- **Голосове введення**: скажіть і перекладіть або диктуйте прямо в будь-яку програму
- **Переклад файлів**: txt, srt, docx і pptx (зі збереженням оформлення), pdf (зокрема скани), зображення
- **Переклад поверх оригіналу**: переклад з'являється просто на місці області, є живий режим для субтитрів
- Власні дії («зробити ввічливіше», «скоротити», свої підказки), історія з пошуком, темна тема

Безкоштовно, відкритий код (MIT). Сторонні компоненти та ліцензії моделей: [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md).

## Встановлення

1. Завантажте **`n17YuHelper-win-Setup.exe`** з [останнього випуску](https://github.com/nieacry/n17YuHelper/releases/latest) і запустіть. Права адміністратора не потрібні; .NET 10 Desktop Runtime встановиться автоматично, якщо його немає.
   Інсталятор поки не має цифрового підпису ([політика підпису](CODE_SIGNING_POLICY.md)), тому Windows SmartScreen може показати *«Windows захистила ваш ПК»*: натисніть **Докладніше → Запустити все одно**.
2. Під час першого запуску програма визначить відеокарту й запропонує потрібні моделі: натисніть **Download recommended** (приблизно 6–10 ГБ для більшості відеокарт). Можна вибрати іншу папку для моделей (**Change models folder...**).
3. У треї з'явиться значок **Yu**. Програма запускається разом із Windows і оновлюється сама (Settings → General → оновлення).

Без інсталятора: `n17YuHelper-win-Portable.zip` — розпакуйте в будь-яку папку.

**Вимоги:** Windows 10/11 x64. Рекомендується відеокарта з 6 ГБ пам'яті і більше (NVIDIA, AMD або Intel); програма працює й на процесорі, але повільно.

| Пам'ять відеокарти | Модель перекладу | Завантаження |
|---|---|---|
| 4 ГБ і менше / без відеокарти | Gemma 4 E2B | ~5,5 ГБ |
| 6–8 ГБ | Gemma 4 E4B | ~7,4 ГБ |
| 10–12 ГБ | Gemma 4 12B | ~9 ГБ |
| 16 ГБ і більше | Gemma 4 26B / 31B | 16–19,5 ГБ |

(Розміри включають PaddleOCR-VL для розпізнавання тексту, ~1,8 ГБ. llama.cpp додає 0,1–0,7 ГБ залежно від відеокарти.)

## Гарячі клавіші за замовчуванням

| Клавіші | Дія |
|---|---|
| Ctrl+Shift+Win+Q | Розумна клавіша: виділений текст, якщо є, інакше область → вікно дій |
| Ctrl+Shift+Win+O | Область → розпізнати текст → у буфер обміну |
| Ctrl+Shift+Win+T | Перекласти (виділений текст або область) |
| Ctrl+Shift+Win+G | Перевірити граматику виділеного тексту |
| Ctrl+Shift+Win+R | Замінити виділений текст його перекладом |
| Ctrl+Shift+Win+A | Перекласти останню область поверх оригіналу (▶ живий режим) |
| Ctrl+Shift+Win+V | Сказати → переклад |
| Ctrl+Shift+Win+D | Сказати → текст у програму (диктування) |
| Ctrl+Shift+Win+W | Знову відкрити останнє вікно дій |

Лівий клік по значку в треї — виділити область; правий — меню. Будь-яку клавішу можна змінити або додати в **Settings → Hotkeys**.

**У вікні дій:** 1 перекласти · 2 розпізнати · 3 граматика · 4 копіювати · 5 замінити в програмі · 6–9 власні дії · Ctrl+M диктувати · Ctrl+O відкрити файл · Ctrl+S зберегти · Esc закрити.

**У рамці виділення:** тягніть — область · клік — вікно чи елемент під курсором · стрілки зсувають на 1 px (Shift — на 10 px) · правий клік скидає · Esc — вийти.

## Приватність

Текст, знімки екрана та голос обробляються локально — llama.cpp на вашому ПК. Програма виходить в інтернет лише щоб завантажити моделі (Hugging Face), llama.cpp (GitHub) та власні оновлення (GitHub). Жодної телеметрії.

## Налаштування та файли

Меню в треї → **Settings...**. Усе зберігається в `settings.json` у папці даних (`%LocalAppData%\n17YuHelper` для встановленої програми; меню в треї → *Open app folder*). Журнал: `logs\yuhelper.log`.

## Проблеми та ідеї

[Створіть issue](https://github.com/nieacry/n17YuHelper/issues) — якщо щось не працює, додайте, будь ласка, `logs\yuhelper.log`.

First public release of **n17 YuHelper** — a Windows tray app that captures a screen region, selected text or your voice with a hotkey and recognizes, translates or proofreads it with **local** AI models (llama.cpp). Nothing is sent to the internet.

- OCR (text, tables, formulas), translation (English, Russian, Ukrainian, Chinese and more), grammar check, custom actions, voice input, file translation (txt, srt, docx, pptx, pdf, images).
- On first start the app detects your GPU and offers to download the right models (about 3–9 GB).
- Automatic updates: the installed app checks GitHub and installs new versions when it is idle (Settings → General).

**Install:** download `n17YuHelper-win-Setup.exe` below and run it. No admin rights needed; .NET 10 Desktop Runtime is installed automatically if missing.
The installer is not code-signed yet, so Windows SmartScreen may show "Windows protected your PC": click **More info → Run anyway**.

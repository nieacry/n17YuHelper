- **Safer downloads:** every model file is checked with SHA256 after downloading; a damaged file is deleted and downloaded again.
- **Tested llama.cpp:** the app installs the llama.cpp build it was tested with instead of whatever is newest. Models → llama.cpp shows the tested version.
- **Choose where models go:** Models → *Change models folder...* — put the 3–20 GB of models on any drive.
- The model list is refreshed from GitHub, so broken links can be fixed without a new app version.
